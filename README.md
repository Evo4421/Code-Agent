# CodeAgent - 代码编写插件

> 一个AstrBot平台的代码编写插件，让AI帮你完成从需求分析到项目交付的全流程。

---

## 📖 简介

CodeAgent是一个AI代码编写插件。你只需要在群聊中艾特机器人并描述你的需求，AI就会自动完成需求分析、方案设计、代码编写、沙箱运行测试、安全审查、质量评估、Debug 循环和项目打包交付。

---

## ✨ 功能特色

- **一键触发**：群聊中 `@机器人 /agent 你的需求` 即可触发
- **全自动流程**：从需求分析到代码交付，无需人工干预
- **沙箱隔离**：代码在隔离环境中运行，安全可靠
- **智能 Debug**：代码运行失败时自动分析错误并修复，最多可配置循环次数
- **安全审查**：自动检测恶意代码、危险操作和敏感路径
- **质量评估**：从文档字符串、嵌套深度、命名规范、注释比例等 10 个维度评分
- **多语言支持**：Python、JavaScript、TypeScript、HTML、CSS、Shell
- **依赖自动补全**：自动生成 requirements.txt 或 package.json
- **一键交付**：多文件项目自动打包为 zip 文件发送

---

## 🔧 工作机制

```

用户需求 → 需求分析 → 方案设计 → 代码编写 → 沙箱测试
↓
安全审查 ← 质量评估 ← 通过 ← 运行成功？
↓                              ↓
通过                           失败 → Debug 循环（最多 N 次）
↓
打包交付 → 用户收到项目文件

```

### 核心流程

| 阶段 | 说明 |
|------|------|
| **阶段一：需求分析** | 解析用户需求，输出设计方案，等待用户确认 |
| **阶段二：代码编写** | 根据方案生成代码，自动补全依赖清单 |
| **阶段三：沙箱测试** | 在隔离环境中运行代码，捕获输出和错误 |
| **阶段四：安全审查** | 检测恶意代码、危险操作、敏感路径 |
| **阶段五：Debug 循环** | 运行失败时自动分析错误、修复代码、重新测试 |
| **阶段六：打包交付** | 通过所有检测后打包为 zip 文件发送给用户 |

## 🚀 使用方法

### 1. 安装插件

在Astrbot WebUI的插件市场下载CodeAgent并应用

2. 触发 CodeAgent

在群聊或私聊中发送以下格式的消息：

```
@机器人 /agent 写一个 Python 脚本，读取 CSV 文件并生成饼图
```

3. 确认方案

AI 会输出设计方案，回复 "确认" 开始编写，或回复修改意见调整方案。

4. 等待交付

AI 会自动完成所有工作，最终交付项目文件。

5. 特殊命令

命令 说明
/exitconver 终止当前正在执行的 Agent 任务

---

⚙️ 配置说明

在 AstrBot WebUI 的插件配置页面可调整以下参数：

配置项 类型 默认值 说明
最大 Debug 次数 int 10 代码运行失败时最多自动修复次数

访问外网 bool false 是否允许沙箱代码访问外网

网络白名单 list pypi.org, github.com... 仅外网开启时生效

代码执行超时 int 120 沙箱代码最大运行时间（秒）

内存限制 float 512 沙箱代码最大内存（MB）

质量评分阈值 int 75 低于此分数触发自动重写

黑名单 list [] 禁止使用 CodeAgent 的用户 ID

群聊黑名单 list [] 禁止使用 CodeAgent 的群号

❓ 常见问题

Q1: 为什么我的 /agent 命令没有触发？

A: CodeAgent 需要同时满足两个条件：

1. 消息中 艾特了机器人（@Evo Gen 3 或 @Evo）
2. 消息中 包含 /agent 和 需求描述

正确示例：@Evo Gen 3 /agent 写一个计算器

Q2: 代码运行失败了怎么办？

A: CodeAgent 会自动进入 Debug 循环，尝试分析错误并修复代码。如果超过最大次数仍然失败，会向您报告并请求人工介入。

Q3: 安全审查拦截了我的代码怎么办？

A: 如果代码中包含危险操作（如 os.system、rm -rf、eval 等），安全审查会拦截并报告。您需要修改需求，避免使用危险操作。

Q4: 质量评分一直低于阈值怎么办？

A: CodeAgent 会自动重写代码尝试提高质量。如果多次重写后仍然低于阈值，建议检查需求是否合理，或手动调整代码。

Q5: 如何查看 Debug 日志？

A: 日志文件位于 ./codeagent_workspace/{session_id}/logs/ 目录下。

Q6: 支持哪些编程语言？

A: 目前支持 Python、JavaScript、TypeScript、HTML、CSS、Shell。用户可以在需求中指定，或使用配置中的默认语言。

Q7: 生成的代码在哪里？

A: 代码通过以下方式交付：

· 多文件项目：打包为 {项目名}_交付.zip 直接发送
· 单文件项目：直接发送文件内容或文件附件

Q8: 如何停止正在运行的 Agent 任务？

A: 发送 @Evo /exitconver 即可立即终止当前任务并清理临时文件。

Q9: 可以同时运行多个 Agent 任务吗？

A: 不可以。CodeAgent 同时只能运行一个任务，新请求会提示等待当前任务完成。

Q10: CodeAgent 会破坏我的系统吗？

A: 不会。所有代码都在沙箱环境中执行，与宿主系统隔离。沙箱限制了 CPU、内存、网络和文件系统访问。
