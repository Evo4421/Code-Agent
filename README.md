# CodeAgent

> 一个 AstrBot 平台的 AI 代码编写插件，让AI帮你完成从需求分析到项目交付的全流程。

---

## 📖 简介

CodeAgent 是一个AstrBot平台的AI代码编写插件。你只需要在群聊中艾特机器人并描述你的需求，AI就会自动完成需求分析、方案设计、代码编写、沙箱运行测试、安全审查、质量评估、Debug循环和项目打包交付。

---

## ✨ 功能特色

- **一键触发**：群聊中 `@机器人 /agent 你的需求` 即可触发
- **全自动流程**：从需求分析到代码交付，无需人工干预
- **多语言支持**：Python、JavaScript、TypeScript、HTML、CSS、Shell
- **沙箱隔离**：代码在隔离环境中运行，安全可靠
- **智能 Debug**：代码运行失败时自动分析错误并修复，最多可配置循环次数
- **安全审查**：自动检测恶意代码、危险操作和敏感路径
- **质量评估**：从 10+ 个维度评分（文档字符串、嵌套深度、命名规范、注释比例等）
- **依赖自动补全**：自动生成 requirements.txt 或 package.json
- **一键交付**：多文件项目自动打包为 zip 文件发送
- **快照与回滚**：每个业务模块完成后自动保存快照，连续失败自动回滚
- **环境自动检测**：自动检测并安装环境
- **JS/TS 完整支持**：ESLint + TypeScript 类型检查 + JSDoc 强制要求
- **多检查器架构**：Python 使用 Ruff+Mypy+Bandit，JS/TS 使用 ESLint+TypeScript+JSDoc

## 🔧 工作机制

```

用户需求 → 精简整合 → 需求分析 JSON → 项目分类（类型/体量）
↓
方案设计 → 用户确认 → 脚手架生成（M/L项目）
↓
工具包 & API 开发 → Ruff + Mypy + Bandit（Python）
↓                    或 ESLint + TypeScript + JSDoc（JS/TS）
Pytest 单元测试（覆盖率 ≥ 90%）
↓
业务模块迭代 → 每模块测试 → 保存快照
↓
代码审查 → 通过 → 打包交付 → 用户收到项目文件

```

### 核心流程

| 阶段 | 说明 |
|------|------|
| **需求精简** | 整合用户提示词，移除冗余内容，输出结构化JSON(人话来说就是让ai能看得更懂) |
| **项目评估** | 判断项目类型和体量（S/M/L）(人话来说就是小，中，大) |
| **方案设计** | 输出设计方案，等待用户确认（60 秒超时自动取消） |
| **脚手架生成** | 大型中型项目自动生成项目结构（src/、tests/、docs/） |
| **核心开发** | 先写工具包和 API，再写业务模块 |
| **质量保障** | 检测错误与隐藏bug与安全问题 Python: Ruff+Mypy+Bandit；JS/TS: ESLint+TypeScript |
| **测试** | Pytest 单元测试 + 边界测试（覆盖率 ≥ 90%，否则不让过） |
| **Debug 循环** | 运行失败时自动分析错误、修复代码、重新测试 |
| **快照回滚** | 每模块完成后保存快照，连续失败 3 次自动回滚 |
| **代码审查** | 逻辑正确性、异常处理、代码复用、性能、安全 |
| **打包交付** | 多文件打包为 zip，单文件直接发送 |

## 🚀 使用方法

### 1. 安装插件

在 AstrBot WebUI 的插件市场下载 CodeAgent 并应用。

### 2. 触发 CodeAgent

在群聊或私聊中发送以下格式的消息：

```

@机器人 /agent 写一个 Python 脚本，读取 CSV 文件并生成饼图

```

### 3. 确认方案

AI 会输出需求分析 JSON 和设计方案，回复 **"确认"** 开始编写，或回复修改意见调整方案。

### 4. 等待交付

AI 会自动完成所有工作（代码编写 → 测试 → Debug → 审查 → 打包），最终交付项目文件。

### 5. 特殊命令

| 命令 | 说明 |
|------|------|
| `/exitconver` | 终止当前正在执行的 Agent 任务，保存状态 |
| `/rollback` | 手动回滚到上一个快照点 |

## ⚙️ 配置说明

在 AstrBot WebUI 的插件配置页面可调整以下参数：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 最大 Debug 次数 | int | 10 | 代码运行失败时最多自动修复次数 |
| 访问外网 | bool | false | 是否允许沙箱代码访问外网 |
| 网络白名单 | list | pypi.org, github.com... | 仅外网开启时生效 |
| 代码执行超时 | int | 120 | 沙箱代码最大运行时间（秒） |
| 内存限制 | float | 512 | 沙箱代码最大内存（MB） |
| 质量评分阈值 | int | 75 | 低于此分数触发自动重写 |
| 黑名单 | list | [] | 禁止使用 CodeAgent 的用户 ID |
| 群聊黑名单 | list | [] | 禁止使用 CodeAgent 的群号 |

## ❓ 常见问题

### Q1: 为什么我的 `/agent` 命令没有触发？

**A**: CodeAgent 需要同时满足两个条件：
1. 消息中 **艾特了机器人**
2. 消息中 **包含 `/agent`** 和 **需求描述**

正确示例：`@我的机器人 /agent 写一个计算器`

### Q2: 代码运行失败了怎么办？

**A**: CodeAgent 会自动进入 Debug 循环，尝试分析错误并修复代码。如果超过最大次数仍然失败，会向您报告并请求人工介入。

### Q3: 安全审查拦截了我的代码怎么办？

**A**: 如果代码中包含危险操作（如 `os.system`、`rm -rf`、`eval` 等），安全审查会拦截并报告。您需要修改需求，避免使用危险操作。

### Q4: 质量评分一直低于阈值怎么办？

**A**: CodeAgent 会自动重写代码尝试提高质量。如果多次重写后仍然低于阈值，建议检查需求是否合理，或手动调整代码。

### Q5: 如何查看 Debug 日志？

**A**: 日志文件位于 `./codeagent_workspace/{session_id}/logs/` 目录下。

### Q6: 支持哪些编程语言？

**A**: 目前支持 **Python、JavaScript、TypeScript、HTML、CSS、Shell**。用户可以在需求中指定，或使用配置中的默认语言。

### Q7: 生成的代码在哪里？

**A**: 代码通过以下方式交付：
- **多文件项目**：打包为 `{项目名}_交付.zip` 直接发送
- **单文件项目**：直接发送文件内容或文件附件

### Q8: 如何停止正在运行的 Agent 任务？

**A**: 发送 `@我的机器人 /exitconver` 即可立即终止当前任务并清理临时文件。

### Q9: 可以同时运行多个 Agent 任务吗？

**A**: 不可以。CodeAgent 同时只能运行一个任务，新请求会提示等待当前任务完成。

### Q10: CodeAgent 会破坏我的系统吗？

**A**: 不会。所有代码都在沙箱环境中执行，与宿主系统隔离。沙箱限制了 CPU、内存、网络和文件系统访问。

### Q11: JS/TS 项目需要额外安装什么吗？

**A**: 不需要。插件启动时会自动检测并安装 Node.js（如果缺失），然后自动执行 `npm i` 安装依赖项。

### Q12: 什么是快照回滚？

**A**: 每完成一个业务模块，CodeAgent 会自动保存当前所有文件的快照。如果后续模块连续失败 3 次，会自动回滚到上一个成功的快照点，避免进度完全丢失。
